# Reusable numerical engine

This package copies the frozen batch arithmetic into independent modules. It has no imports from `l2_batch1..3`, `did_samples`, or `insight`, and no fixed case list. Existing batches retain their original code. `LINEAGE.json` records source byte hashes at extraction.

`runner.fit_primary(declaration, rows, interval_evaluation_path=...)` returns `(payload, design, outcomes)`. `fit_row` is the same function: primary and every registered sensitivity follow the same topology, numerical contrast and endpoint-reference path. The payload contains `status`, `result` and `reference`; writing official results and verifying approval belong to the stage dispatcher.

`Declaration` in `types.py` binds a case calendar/window/sample mask, cohort and operative clocks, certified never-controls, and optional explicit exposure histories. If `period_years` is present, rows contain calendar labels while clocks/cohorts use their consecutive indices. `design.declaration_from_support(source, summary, key=...)` adapts arbitrary annual frozen metadata summaries. Policy-specific clock/scope rulings supply explicit metadata or `operative_override`.

`panels.PanelBinding` binds source, complete registered replacement, and exact metadata mask by hashes. `audit_binding` hashes opaque bytes and projects only unit/year prefixes; `load_bound_panel` reads values using the identical mask and merge. The registered replacement includes historical rows; partial overlays use `load_variant` with explicit replacement years.

`calibration.blind_anchor` converts only a pooled rectangle strictly before earliest operative onset. `calibration_operators` uses zero-valued metadata rows; `calibrate_synthetic` and `evaluate_intervals` consume invented paths. Default simulation counts and seeds remain Protocol v2. No failed calibration is retuned. Webb is selected first across the complete registered design inventory, then CT; if both fail, no interval is reported. `certify_intervals` validates 1000 clean worlds, 4999 draws, 100 retained held-out records, per-design coverage and width gates. `design_binding` hashes both structural exposure/masks and fixed ATT/donor operators. Reporting requires this complete certificate and the authoritative planned inventory. Candidate failures are retained independently.

`ri.permutation_reference` predraws fixed adoption/operative/exposure/control-eligibility bundles, retains failed draw indices, excludes infeasible assignments without redraw, and requires at least 90% feasibility. `noise.noise_summary` requires the registered 999 requested draws and describes a relabeling reference, not a confidence interval. Parallel orchestration may map `one_reference` over predrawn bundles; order and RNG must remain unchanged.

Run `.venv_did/bin/python -B -m unittest scripts.l2_pipeline.tests.test_equivalence -v`. The archival test opens only one existing batch2 design's frozen inputs and compares all canonical point, SE and independent-reference fields and suppresses the legacy uncertified interval artifact; it never writes an official result. The pure numerical functions also support invented tests, and must be called from a final-approved dispatcher for new real studies.
