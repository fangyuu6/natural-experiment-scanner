# src

策略追踪流水线和网站报告层的主工作目录，包含数据采集、LLM 分析、导出和测试的全部代码与运行时产出。

## 文件

- `config/` — 数据源配置（源目录、API 密钥映射等）
- `data/` — 输入数据集和源扩展产物
- `docs/` — 项目文档（列定义、交叉匹配说明、评分系统等）
- `export/` — CSV / HTML 导出模块
- `extraction/` — LLM 提取、预过滤、评分和混杂因素分析逻辑
- `ingestion/` — 各数据源的抓取器和采集模块
- `output/` — 脚本运行产出（策略数据库、HTML 报告、基准测试等）
- `scripts/` — 操作运行器、审计脚本、基准测试任务和资源生成器
- `tests/` — 活跃脚本和模块的回归测试
