# config

项目配置包，集中管理 API 密钥、LLM 模型定义、评分权重等全局常量与环境变量，供整个管道共享。

## 文件

- `__init__.py` — 包初始化（仅标记为 Python 包）
- `facts.py` — 项目核心事实常量的唯一可信源：prompt 版本、评分权重、可行性门槛、基准测试结果、跨模型精度指标等
- `models.py` — 跨模型评估所用的 LLM 模型配置（OpenRouter 路由），包括主分析模型和评审裁判模型
- `settings.py` — 从环境变量加载运行时配置：各数据源 API 密钥、LLM 端点、默认抓取数量等
- `source_catalog.py` — 数据来源注册表：定义每个来源的显示名、域名匹配、批量导入函数、去重策略，并提供 URL/ID 到来源的推断逻辑
